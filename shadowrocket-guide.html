小火箭 Shadowrocket：下载和配置一篇搞定

2026-09-07

它是个啥

Shadowrocket（大家叫它小火箭）是 iOS 上最常用的代理工具，支持 SS、SSR、V2Ray、Trojan 等多种协议，由 Shadow Launch Studio 开发，在美区 App Store 售价 2.99 美元。

三种下载方式

  1. 用美区 Apple ID 登录 App Store，直接搜"Shadowrocket"购买下载（2.99 美元）。
  2. 用别人的共享美区 ID 只下载 App——注意只登录 App Store 下东西，千万别登 iCloud。
  3. 嫌折腾的话，在 CC-🍎 入手一个成品美区 ID，下载完自己改密码，长期用着也安心。

配置三步走

1. 添加节点

打开小火箭点右上角"+"，选类型（SS / SSR / V2Ray / Trojan）手动填写；或者更省事的：点首页"订阅"，粘贴订阅链接后更新，节点自动导入。

2. 选路由模式

  • 全局路由：所有流量都走代理，速度最慢。
  • 按规则分流：国内直连、国外走代理（推荐，速度和体验最平衡）。
  • 场景模式：按网络环境自动切换。

3. 打开开关

点首页的大开关就行。第一次会弹窗"Shadowrocket 想添加 VPN 配置"，点允许并输入锁屏密码。

常见问题

Q：连上后上不了网？
A：查三样——节点有没有效、路由规则对不对、换全局模式试试。

Q：费电吗？
A：正常用几乎无感。异常耗电多半是规则配得有问题，导致一直重连。

Q：更新要重新买吗？
A：不用，用当初购买的那个 Apple ID 登录 App Store 免费更新。
