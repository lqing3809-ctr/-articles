官网能登录，App Store 却"验证失败"？两招搞定

2026-10-23

密码明明是对的，App Store 就是弹"验证失败"或"连接服务器出错"。别慌，按顺序试下面两招，第一招不行再试第二招。

第一招：校准 iPhone 的日期和时间

老机型的时间服务器偶尔和苹果的验证服务器对不上，就会这样。

  1. 打开"设置 → 通用 → 日期与时间"。
  2. 先把"自动设置"关掉，检查时区、日期、时间是不是你所在地的正确时间（比如在国内就用北京时间）。
  3. 回到 App Store 重新登录一次。
  4. 登录成功后，再回来把"自动设置"打开，确认时间依然正确。

如果时间本来就是对的、还是失败，往下看第二招。

第二招：给当前 Wi-Fi 手动设个 DNS

  1. 打开"设置 → 无线局域网"，确认连着 Wi-Fi。
  2. 点当前网络名称右边的 ⓘ。
  3. 找到"配置 DNS"，点进去选"手动"，添加服务器 8.8.8.8，点右上角存储。
  4. 回 App Store 再登录一次。

登录成功后，可以回到同一页面把 DNS 改回"自动"。

为啥会这样

多数情况就是设备时间和苹果服务器时间对不上，验证握手失败。按上面两步走，基本都能解决。
